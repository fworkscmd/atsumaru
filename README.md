# PITOPA（ピトパ）

ピッとかざして、パッと集まる。
NFCコインをスマホにかざして同じ卓に集まり、1人1台で遊ぶパーティーゲーム集です（ver 1.2）。

- **ドワーフ** … 深掘りチキンレース（2〜4人）
- **トラッパー** … 罠士 VS 鳥3羽のすごろく（1〜4人、足りない席はNPC）

## はじめかた

1. [Node.js](https://nodejs.org/)（LTS版）を入れる
2. このフォルダを VS Code で開く
3. ターミナルで `npm run dev`（`src/` を保存するたびに `index.html` が作り直されます）
4. VS Code の拡張機能「Live Server」で `index.html` を開く → 保存するとブラウザが自動で更新

公開は `index.html` をふくめて GitHub に push するだけ（GitHub Pages）。
Firebase の設定は `docs/firebase-setup.md`、開発のくわしいメモは `CLAUDE.md` にあります。
